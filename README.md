# Agent Blackbox

Alpha recorder for agent workflows. Wrap a function, store signed event records
with evidence digests and declared links, then inspect an incident or verify
local record integrity.

## Core Features

| Feature | Description |
|---|---|
| Trace decorator | Wrap agent functions and record runtime events |
| JEP-style event | Emits JEP Core 0.7-style J/D/T/V event objects with stable Event Identity |
| Declared links | Records parent relationships for incident review |
| Evidence digests | Records input/output/error digests |
| Local blackbox log | Stores JSONL event records for later review |
| Incident review | Reconstructs declared chain fragments around an incident |
| Integrity check | Verifies event hashes and Ed25519 signatures generated by this library |

## Installation

Install the published distribution:

```bash
pip install --pre agent-blackbox-jep
```

The distribution is `agent-blackbox-jep`, the Python import is `agent_blackbox`,
and the CLI commands are `agent-blackbox` and `blame-finder`.

For local development:

```bash
pip install -e .
```

## Basic Usage

```python
from agent_blackbox import AgentBlackbox

blackbox = AgentBlackbox(storage="./blackbox_logs")

@blackbox.trace(agent_name="CoderAgent")
def write_code(requirement: str) -> str:
    return "print('hello world')"

result = write_code("write a hello world")

# Review the latest event
event_hash = list(blackbox.events.keys())[-1]
report = blackbox.review_incident(event_hash)

print(report["candidate_failure_node"])
print(report["chain"])
```

## CLI

Review an incident:

```bash
agent-blackbox review sha256:...
```

Show a chain tree:

```bash
agent-blackbox tree sha256:...
```

Verify an event:

```bash
agent-blackbox verify sha256:...
```

## Boundary Statement

New events use [Core 0.7](https://github.com/hjs-spec/jep-core#current-contract)
with Event Identity `(who,id)`. Event Hash identifies the exact signed artifact
and is the lookup key in the local store. The trace decorator records judgments;
D/T/V events require explicit creation with their required fields.

Verification checks event integrity under the recorder's local key and the recorded
links. It does not establish factual causality, legal responsibility or log
completeness. See the [current alpha releases](https://github.com/hjs-spec/Agent-Blackbox/releases)
for the packaged implementation.
